В этом проекте будет написано тестовое задание по следующему ТЗ:
1. Программа должна искать данные в заданном каталоге и подкаталогах.
2. Имя файла может задаваться: целиком, по маске, по регулярному выражению(не обязательно).
3. Программа должна запускаться с параметрами.
   Ключи:
   -d - директория, в которой начинать поиск.
   -n - имя файла, маска, либо регулярное выражение.
   -t - тип поиска: mask искать по маске, name по полному совпадение имени, regex по регулярному выражению.
   -o - результат записать в файл.
4. Параметры в программу должны передаваться в командной строке.
5. Программа должна записывать результат в файл.
6. В программе должна быть валидация ключей и подсказка.
